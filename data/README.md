# Data

This project uses the NASA C-MAPSS FD001 Turbofan Engine Degradation Dataset.

The raw dataset is not uploaded directly to this repository because it should be downloaded from the official NASA Prognostics Center of Excellence data source.

Dataset used:

- NASA C-MAPSS FD001
- Turbofan engine sensor readings
- Training engine data
- Test engine data
- Remaining Useful Life labels

The dataset was used in Databricks for raw loading, cleaning, feature engineering, model training, inference testing, and dashboard output generation.
